# n8n-nodes-wecom

这是一个 n8n 社区节点，让你可以在 [n8n](https://n8n.io/) 工作流中使用企业微信（WeChat Work）API。

## 安装

在 n8n 中通过社区节点管理界面搜索 `n8n-nodes-wecom` 进行安装，或使用命令行：

```bash
npm install n8n-nodes-wecom
```

详细安装指南请参考 [n8n 社区节点文档](https://docs.n8n.io/integrations/community-nodes/installation/)。

## 凭证配置

### 消息推送功能（群机器人 Webhook）

**消息推送**功能用于通过群机器人 Webhook 发送消息到企业微信群聊。此功能特点：
- 使用群机器人的 Webhook URL 发送消息
- 无需配置企业ID、应用Secret等复杂凭证
- 适合快速发送通知消息到群聊

#### 配置步骤：
1. 在企业微信群聊中，点击右上角"..."菜单
2. 选择"群机器人" > "添加机器人"
3. 创建一个机器人并复制 Webhook 地址
4. 在 n8n 中配置"企业微信群机器人 Webhook"凭证，填入 Webhook 地址

### 获取企业微信凭证（消息发送、通讯录、素材管理功能需要）

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)
2. 进入"我的企业" > "企业信息"，复制 **企业ID (CorpID)**
3. 进入"应用管理" > 选择或创建一个应用
4. 复制 **AgentId**（应用ID）
5. 点击"查看Secret"，复制 **Secret**

### 在 n8n 中配置

1. 添加"企业微信"节点到工作流
2. 根据使用的功能选择对应的凭证：
   
   **消息推送（群机器人）：**
   - 点击"Credential to connect with"
   - 选择"创建新凭证 - 企业微信群机器人 Webhook"
   - 填入群机器人的 Webhook URL
   
   **应用消息、通讯录、素材管理：**
   - 点击"Credential to connect with"
   - 选择"创建新凭证 - 企业微信 API"
   - 填入以下信息：
     - **企业 ID** - 你的企业 CorpID
     - **应用 Secret** - 应用的 Secret
     - **应用 ID** - 应用的 AgentID
   
   **消息接收（Trigger 节点）：**
   - 添加"企业微信消息接收"触发器节点
   - 点击"Credential to connect with"
   - 选择"创建新凭证 - 企业微信消息接收 API"
   - 填入以下信息：
     - **企业 ID** - 你的企业 CorpID
     - **Token** - 你将在企业微信后台设置的 Token（两边必须一致）
     - **EncodingAESKey** - 你将在企业微信后台设置的密钥（两边必须一致，43位字符）
   - 复制节点的 Webhook URL
   - 在企业微信应用管理后台配置接收消息时，使用**相同的** Token 和 EncodingAESKey
   
   > 💡 **说明**：Token 和 EncodingAESKey 是你自己设置的"暗号"，用于确保消息安全。节点会自动使用这些参数验证签名和解密消息，你无需手动处理这些步骤

### 权限配置

确保应用具有以下权限（在应用的"API权限"中开启）：

- ✅ 消息发送权限（用于应用消息）
- ✅ 通讯录读取权限（读取成员、部门、标签信息）
- ✅ 素材管理权限
- ✅ 应用可见范围（建议设置为全员）

**注意**：消息推送功能使用群机器人，无需配置应用权限

## 消息接收配置指南

### 配置流程说明

企业微信的消息接收采用**加密传输 + 签名验证**机制。你需要设置一个"暗号"（Token 和 EncodingAESKey），企业微信和 n8n 使用相同的"暗号"来确保通信安全。

**重要**：签名验证和消息解密都由节点自动完成，你只需要在两边配置相同的参数即可。

### 配置步骤

#### 第1步：在 n8n 中准备

1. 在 n8n 中添加"企业微信消息接收"触发器节点
2. 创建凭证，先随意填写一个 Token 和 EncodingAESKey（后续会在企业微信中使用相同的）：
   - **Token**: 例如 `my_secret_token_123`（建议使用随机字符串）
   - **EncodingAESKey**: 例如点击企业微信后台的"随机生成"获取43位字符串
3. 保存凭证，复制节点生成的 **Webhook URL**

#### 第2步：在企业微信中配置

1. 登录企业微信管理后台，进入"应用管理"
2. 选择你的应用，找到"接收消息"配置区域
3. 填入以下参数（**必须与 n8n 中的完全一致**）：
   - **URL**: 粘贴刚才复制的 Webhook URL
   - **Token**: 填写与 n8n 凭证中**完全相同**的值
   - **EncodingAESKey**: 填写与 n8n 凭证中**完全相同**的值（或点击"随机生成"后复制到 n8n）
4. 点击"保存"

#### 第3步：自动验证

- 当你点击"保存"时，企业微信会自动向你的 Webhook 发送验证请求
- n8n 节点会自动：
  1. 验证签名
  2. 解密验证码
  3. 返回正确的响应
- 验证成功后即可开始接收消息

#### 第4步：接收消息

配置完成后，当用户向应用发送消息时：
1. 企业微信自动加密消息并发送到你的 Webhook
2. n8n 节点自动验证签名、解密消息
3. 工作流被触发，你可以在后续节点中处理消息

**你无需编写任何代码来处理加密和签名验证，节点会自动完成这些步骤！**

### 接收到的消息格式

消息数据会包含以下字段（根据消息类型不同而不同）：

```json
{
  "ToUserName": "企业ID",
  "FromUserName": "发送者UserID",
  "CreateTime": "消息创建时间",
  "MsgType": "消息类型（text/image/voice/video等）",
  "Content": "文本消息内容",
  "MsgId": "消息ID",
  "AgentID": "应用ID",
  "receivedAt": "接收时间（ISO格式）"
}
```
