# n8n-nodes-wecom

这是一个 n8n 社区节点，让你可以在 [n8n](https://n8n.io/) 工作流中使用企业微信（WeChat Work）API。

## 安装

在 n8n 中通过社区节点管理界面搜索 `n8n-nodes-wecom` 进行安装，或使用命令行：

```bash
npm install n8n-nodes-wecom
```

详细安装指南请参考 [n8n 社区节点文档](https://docs.n8n.io/integrations/community-nodes/installation/)。

## 凭证配置

### 消息推送功能（无需凭证）

**消息推送**功能用于接收企业微信服务器推送的消息和事件，**无需配置API凭证**。此功能适用于：
- 接收用户发送给应用的消息
- 接收企业微信的事件通知（成员变更、部门变更等）

使用消息推送功能时，请选择"消息推送"资源类型，然后根据需要选择对应的操作即可。

### 获取企业微信凭证（消息发送、通讯录、素材管理功能需要）

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)
2. 进入"我的企业" > "企业信息"，复制 **企业ID (CorpID)**
3. 进入"应用管理" > 选择或创建一个应用
4. 复制 **AgentId**（应用ID）
5. 点击"查看Secret"，复制 **Secret**

### 在 n8n 中配置

1. 添加"企业微信"节点到工作流
2. 如果使用消息发送、通讯录或素材管理功能：
   - 点击"Credential to connect with"
   - 选择"创建新凭证 - 企业微信 API"
   - 填入以下信息：
     - **企业 ID** - 你的企业 CorpID
     - **应用 Secret** - 应用的 Secret
     - **应用 ID** - 应用的 AgentID
3. 如果使用消息推送功能，则无需配置凭证

### 权限配置

确保应用具有以下权限（在应用的"API权限"中开启）：

- ✅ 消息发送权限
- ✅ 消息接收权限（用于消息推送）
- ✅ 通讯录读取权限（读取成员、部门、标签信息）
- ✅ 素材管理权限
- ✅ 应用可见范围（建议设置为全员）
