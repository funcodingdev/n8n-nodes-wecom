# 企业微信群机器人 Webhook 使用指南

## 概述

群机器人 Webhook 功能允许你通过简单的 HTTP 请求向企业微信群聊发送消息。此功能**无需配置企业ID、应用Secret等复杂凭证**，只需要群机器人的 Webhook URL 即可。

## 功能特性

### 支持的消息类型

1. **文本消息** - 发送纯文本内容，支持@成员
2. **Markdown 消息** - 发送支持 Markdown 格式的富文本消息
3. **Markdown V2 消息** - 发送支持更多 Markdown 语法的富文本消息
4. **图片消息** - 发送图片（Base64 或 MD5）
5. **图文消息** - 发送包含标题、描述、链接和图片的图文消息
6. **文件消息** - 发送文件
7. **语音消息** - 发送语音文件
8. **模板卡片消息** - 发送交互式卡片消息
   - 文本通知模板卡片
   - 图文展示模板卡片

## 配置步骤

### 1. 创建群机器人

1. 在企业微信群聊中，点击右上角"..."菜单
2. 选择"群机器人" > "添加机器人"
3. 设置机器人名称和头像
4. 复制生成的 **Webhook 地址**（格式：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx`）

### 2. 在 n8n 中配置凭证

1. 在 n8n 工作流中添加"企业微信"节点
2. 选择资源类型为"消息推送"
3. 点击"Credential to connect with"
4. 选择"创建新凭证 - 企业微信群机器人 Webhook API"
5. 填入刚才复制的 Webhook URL
6. 点击"保存"

## 使用示例

### 示例 1: 发送文本消息

**配置**:
- 资源: `消息推送`
- 操作: `发送文本消息`
- 消息内容: `项目部署成功！`
- @成员: `zhangsan|lisi`（可选）
- @手机号: `13800000000`（可选）

**效果**: 在群聊中发送一条文本消息，并@指定的成员

### 示例 2: 发送 Markdown 消息

**配置**:
- 资源: `消息推送`
- 操作: `发送 Markdown 消息`
- Markdown 内容:
```markdown
# 系统监控告警
> 服务器状态异常

**详细信息：**
- 服务器：web-01
- CPU使用率：<font color="warning">85%</font>
- 内存使用：<font color="info">70%</font>

[查看详情](https://monitor.example.com)
```

**效果**: 在群聊中发送一条格式化的 Markdown 消息

### 示例 3: 发送图片消息

**配置**:
- 资源: `消息推送`
- 操作: `发送图片消息`
- 图片来源: `Base64`
- Base64 图片: `iVBORw0KGgoAAAANSUhEU...`（图片的Base64编码）

**效果**: 在群聊中发送一张图片

### 示例 4: 发送图文消息

**配置**:
- 资源: `消息推送`
- 操作: `发送图文消息`
- 图文列表:
  - 标题: `n8n 工作流自动化平台`
  - 描述: `强大的工作流自动化工具，连接你的所有应用`
  - 跳转链接: `https://n8n.io`
  - 图片链接: `https://n8n.io/logo.png`

**效果**: 在群聊中发送一条可点击的图文消息

### 示例 5: 发送文件消息

**配置**:
- 资源: `消息推送`
- 操作: `发送文件消息`
- Media ID: `3a28fd78c09d23d39b12345678abcdef`

**效果**: 在群聊中发送一个文件

**注意**: 文件需要先通过临时素材接口上传获取 media_id

## 工作流集成示例

### 场景 1: 监控告警通知

```
Webhook 触发器 → HTTP 请求(监控API) → IF 节点(判断阈值) → 企业微信(消息推送-发送Markdown)
```

当监控系统检测到异常时，自动发送格式化的告警消息到群聊。

### 场景 2: CI/CD 部署通知

```
GitHub Webhook → 企业微信(消息推送-发送文本) → @开发人员
```

代码部署完成后，自动通知相关开发人员。

### 场景 3: 定时报表推送

```
Cron 节点 → 数据库查询 → 生成图表 → 企业微信(消息推送-发送图文)
```

每天定时生成业务报表并推送到群聊。

### 场景 4: 订单通知

```
数据库触发器 → 格式化数据 → 企业微信(消息推送-发送Markdown)
```

新订单产生时，自动发送订单详情到群聊。

## Markdown 语法支持

群机器人支持以下 Markdown 语法：

- **标题**: `# 一级标题`, `## 二级标题`
- **加粗**: `**加粗文本**`
- **斜体**: `*斜体文本*`
- **链接**: `[链接文字](URL)`
- **引用**: `> 引用内容`
- **代码**: \`行内代码\`
- **颜色字体**: `<font color="info">文字</font>`（支持：info、comment、warning）

## 注意事项

### 频率限制

- 每个机器人每分钟最多发送 20 条消息
- 如果超过频率限制，会收到限流错误

### 消息长度限制

- 文本消息：最长 2048 字节
- Markdown 消息：最长 4096 字节
- 图片：Base64 编码前最大 2MB，支持 JPG/PNG 格式

### @成员功能

- 可以使用 userid 或手机号@群成员
- 使用 `@all` 可以@所有人
- 多个成员用 `|` 分隔

### 图片要求

- 使用 Base64 方式：图片不含 `data:image` 前缀
- 使用 MD5 方式：需要提供图片内容的 MD5 值

### 文件上传

文件消息需要先上传到企业微信临时素材库：
1. 使用"素材管理">"上传临时素材"功能
2. 获取返回的 media_id
3. 将 media_id 用于发送文件消息

## 错误处理

### 常见错误码

- `93000`: 参数错误（检查消息格式）
- `93004`: 机器人被禁用（联系管理员）
- `93008`: 文件不存在（检查 media_id）
- `45009`: 接口调用超限（降低发送频率）

### 最佳实践

1. **启用错误处理**: 在节点配置中启用"Continue On Fail"
2. **添加重试逻辑**: 使用 n8n 的重试功能处理临时故障
3. **日志记录**: 记录发送的消息便于问题排查
4. **消息去重**: 避免短时间内发送重复消息
