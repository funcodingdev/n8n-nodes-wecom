## 旧版jweixin调用
### 示例代码
```javascript
wx.getBLEDeviceCharacteristics({
 // 这里的 deviceId 需要已经通过 createBLEConnection 与对应设备建立链接
 deviceId,
 // 这里的 serviceId 需要在 getBLEDeviceServices 接口中获取
 serviceId,
 success (res) {
 console.log('device getBLEDeviceCharacteristics:', res.characteristics)
 }
})
```
