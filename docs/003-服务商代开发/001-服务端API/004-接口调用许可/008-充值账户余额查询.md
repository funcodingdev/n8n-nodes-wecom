**请求方式：** GET（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/service/get_account_balance?provider_access_token=ACCESS_TOKEN

**参数说明：** 

| 参数 | 是否必须 | 说明 |
| ------- | ---- | ---- |
| provider_access_token | 是 | 应用服务商的接口调用凭证，获取方法参见[服务商的凭证](#15143 ) |

**返回结果：**
```
{
  "errcode": 0,
  "errmsg": "ok",
  "balance": 1000090
}
```
**参数说明：**

| 参数 | 说明 |
| ------- | ---- |
| errcode |错误码 |
|errmsg|错误码说明| 
|balance|充值账户余额，单位为分|
