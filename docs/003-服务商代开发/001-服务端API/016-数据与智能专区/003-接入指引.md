##接入指引
###一、创建应用
新增「外部服务应用」类型，不同于传统的“工作台应用”，外部服务应用无需配置应用主页。它适用于那些**获取数据后在外部环境提供服务**的应用场景。服务商可在服务商助手中创建该类应用。
- ![enter image description here](https://wework.qpic.cn/wwpic3az/571632_Qvanb2zASXis3kk_1770714658/0)

在创建应用并申请数据权限时，服务商须提交**数据用途说明**。该说明将直接展示在企业端的授权页面中，作为企业管理员决策的重要参考。请务必提供清晰、准确的描述（包括使用场景、目的及处理逻辑），以提升企业的信任度及授权通过率。
- ![enter image description here](https://wework.qpic.cn/wwpic3az/845536_-vg798iYSfGr8Kx_1770713424/0)

###二、应用授权
外部服务应用发布后，服务商可通过应用二维码引导企业管理员扫码授权（外部服务应用不支持成员授权）。
- ![enter image description here](https://wework.qpic.cn/wwpic3az/860646_HGlcSe18SxC89tx_1770714197/0)

###三、数据权限授权
应用授权成功后，若应用申请了数据接口权限，需要企业管理员二次授权。授权通过后，应用才可调用企业的数据接口。详情可参看[获取数据权限接入指引](#61441)
