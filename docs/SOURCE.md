## 同步规则

1. 拉取官方目录树，按 `order_id` 排序生成 `序号-标题` 路径
2. 文档 ID 为 `wecom_` + `sha256(路径)` 前 12 位，直接从 SpecFusion 获取正文
3. 路径未命中时按标题搜索，并用原文链接（`source_url`）校验后再取正文
4. frontmatter 记录 `specfusion_id`、`source_url`、`last_updated`、`synced_at`
5. 接口最终以官网最新文档为准
