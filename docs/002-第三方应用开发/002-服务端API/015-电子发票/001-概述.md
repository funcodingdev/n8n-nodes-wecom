1. 用户在应用中发票报销，选择电子发票类型；
2. 应用调用JS-SDK“[chooseInvoice接口](#10029/拉起电子发票列表)”拉起微信卡包，展示发票列表
3. 用户选择电子发票提交报销；
4. 报销方调用API接口查询发票信息，核实后锁定电子发票
5. 报销方打款给用户后，调用接口核销电子发票

相关功能介绍请参考“[电子发票平台](https://fapiao.weixin.qq.com)”
