## 创建部门事件
当学校在家校通讯录中创建部门时，回调此事件至第三方应用/套件的指令回调URL。

请求示例：

```
<xml>
 <SuiteId><![CDATA[wwSuiteId]]></SuiteId>
 <AuthCorpId><![CDATA[wxAuthCorpId]]></AuthCorpId>
 <InfoType><![CDATA[change_school_contact]]></InfoType>
 <TimeStamp>1403610513</TimeStamp>
 <ChangeType><![CDATA[create_department]]</ChangeType>
 <Id>1</Id>
</xml>
```
参数说明：

 | 参数 | 说明 |
 |----|---- |
 |SuiteId|第三方应用ID |
 |AuthCorpId|授权企业的CorpID |
 |CreateTime|消息创建时间 （整型） |
 |InfoType|事件的类型，此时固定为change_school_contact |
 |ChangeType|此时固定为create_department |
 |Id|新建部门的Id |
