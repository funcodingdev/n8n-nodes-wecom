通过该接口可获取授权企业中文件内容存档所有生效中的成员列表。

**权限说明**

| 应用类型 | 权限要求 |
| -------- | ---- | 
|自建应用|需具备「!!#ff0000 数据与智能专区-分析企业文件数据!!」权限 |
|代开发应用|需具备「!!#ff0000 数据与智能专区-分析企业文件数据!!」权限|
|第三方应用|需具备「!!#ff0000 数据与智能专区-分析企业文件数据!!」权限|
> 分析企业文档数据权限需要企业管理员二次授权
> 企业或服务商需已灰度文件内容存档功能

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/docdata/get_auth_user_list?access_token=ACCESS_TOKEN

**请求包体**
```
{
  "cursor":"JMgigeong",
  "limit":2
}
```

**参数说明：** 

| 参数 | 是否必须| 类型| 说明 |
| ------- | ---- | --|-- |
|access_token|是|String|调用接口凭证|
|cursor|否|String|上一次调用时返回的next_cursor，第一次拉取可以不填|
|limit|否|Interger|本次查询返回的最大条数。不超过1000，默认200条|

**返回结果：**
```
{
 "errcode": 0,
 "errmsg": "ok",
 "auth_user_list": [
 {
 "userid": "woxxxjigegen"
 },
 {
 "userid": "woaaaaaaaaaa"
 }
 ],
 "next_cursor": "xjigeojgeigwj",
 "has_more": true
}
```
**参数说明：**

| 参数 | 类型|说明 |
| ------- | --|-- |
| errcode |Integer|错误码 |
|errmsg|String|错误码说明|
|auth_user_list|Object数组|生效成员列表，详见**AuthUser**|
|next_cursor|String|下一次查询时使用，将值填到请求包的cursor字段中|
|has_more|Integer|是否还有更多未拉取的数据，1：是；0：否|

**AuthUser**
| 参数 | 类型|说明 |
| ------- | ---|---|
|userid|String|授权成员的userid|
