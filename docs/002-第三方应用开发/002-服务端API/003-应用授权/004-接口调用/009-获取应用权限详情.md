**请求方式：**POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/agent/get_permissions?access_token=ACCESS_TOKEN

**参数说明：** 
 
 | 参数 | 是否必须 | 说明 |
 |----|---- | ----- |
 | access_token | 是 | 代开发自建应用access_token，获取方法参见[获取access_token](#15074)<br>第三方应用access_token，获取方法参见[获取企业凭证](#14944) |

 
**权限说明：** 
支持所有的代开发应用和第三方应用调用

**返回结果：** 
```
{
  "errcode":0 ,
  "errmsg":"ok",
  "app_permissions":["xxx:xxx:xx"],
  "app_permissions_ext": [
    {
      "permission_name": "xxx:xxx:xx",
      "expire_time": 1770100000
    }
  ]
}
 ```
**参数说明：** 

 | 参数 | 说明 |
 |----|---- |
 |errcode|错误码 |
 |errmsg|错误描述 |
 |app_permissions| 应用的权限列表，应用权限为字符串类型，应用权限对应的字符串描述参考附录。|
 |app_permissions_ext|应用权限的扩展信息，若存在应用权限为二次授权并且有时效时，返回该字段列表。特殊情况，若权限不会过期则expire_time字段值为0|
 |app_permissions_ext.permission_name|权限名称|
 |app_permissions_ext.expire_time|秒级时间戳，权限过期时间|
