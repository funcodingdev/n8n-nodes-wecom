**请求方式：**GET（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/sync/contact_sync_success?access_token=ACCESS_TOKEN

**参数说明：**

| 参数 | 是否必须 | 说明 |
|----|---- | ----- |
| access_token | 是 |查询注册状态接口返回的access_token（跟注册完成回调事件的AccessToken参数一致，请注意与provider_access_token的区别）|
 
 
**返回结果：** 

```
{
 "errcode":0,
 "errmsg":"ok"
}
```
