  <InfoType><

**参数说明：**

 | 参数 | 说明 |
 |----|---- |
 |ServiceCorpId|服务商corpid |
 |InfoType|事件类型，此处固定为enter_register_package |
 |TimeStamp|回调事件的时间戳 |
 |AuthCorpId|扫描推广二维码的成员所属企业corpid|
 |AuthUserInfo|扫描推广二维码的成员信息 |
 |UserId|成员的userid|
 |RegisterCode|注册链接对应的注册码|
 |State|自定义的状态值，参数值由接口 [获取注册码](#14934) 指定。若未指定，则无该字段|
 |TemplateId|推广包ID|
