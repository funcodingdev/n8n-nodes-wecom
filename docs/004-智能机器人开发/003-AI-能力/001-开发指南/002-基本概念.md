## API 模式

智能机器人支持两种工作模式：

| 模式 | 说明 |
|---|---|
| **普通模式** | 由企业微信内置能力处理对话，无需开发 |
| **API 模式** | 开发者自定义消息处理逻辑，通过开放接口接入自有系统 |

开发者需开启 **API 模式** 才能使用消息收发、CLI、MCP 等开放能力。

---

## 机器人凭证

机器人的身份凭证用于建立连接或校验请求来源。不同连接方式使用不同凭证：

| 凭证 | 连接方式 | 用途 |
|---|---|---|
| `BotID` | 长连接 | 机器人唯一标识，建立长连接时携带 |
| `Secret` | 长连接 | 身份密钥，用于订阅连接时的身份校验 |
| `Token` | URL 回调 | 用于生成签名，校验回调请求来源合法性 |
| `EncodingAESKey` | URL 回调 | 消息体加解密密钥 |

> 凭证在管理后台机器人编辑页获取，请妥善保管，切勿泄露。

---

## 消息与事件

**消息**：用户主动发送给机器人的内容，包括文本、图片、语音、文件、视频等类型。

**事件**：用户操作触发的通知，包括进入会话、点击模板卡片按钮、对回复点赞/踩等类型。

---

## 回调

企业微信通过**回调**将消息和事件实时推送给开发者的服务。开发者不需要主动轮询，企业微信在事件发生时主动发起请求。

两种连接方式的回调机制不同：

| | 长连接 | URL 回调 |
|---|---|---|
| **推送方式** | 通过已建立的长连接实时推送 | 向开发者配置的 URL 发起 HTTP POST 请求 |
| **加解密** | 无需，明文 JSON | 需要，使用 Token 和 EncodingAESKey |
| **流式消息** | 开发者主动推送更新，企业微信实时展示 | 企业微信轮询回调 URL 获取最新内容 |
| **高可用** | 同一机器人仅允许一个有效连接 | 支持多实例负载均衡 |

## CLI

CLI（`wecom-cli`）是企业微信提供的命令行工具，支持对文档、日程、会议、待办等企业数据进行读写操作。

CLI 以**机器人身份**代替成员调用企业微信接口。成员需授权对应能力权限，CLI 才能访问该能力数据。

典型场景：在消息回调中调用 CLI 读取成员待办，汇总后通过消息接口回复给用户。

详见[CLI 概述](#61944)。

---

## MCP

MCP 将企业微信数据能力以 MCP 协议对外提供，AI 工具可通过标准接口直接读写企业微信数据。

详见 [MCP 能力概述](#61954)。
