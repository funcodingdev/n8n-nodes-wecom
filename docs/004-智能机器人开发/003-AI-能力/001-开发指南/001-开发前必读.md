## 消息收发前置配置

使用消息收发能力前，需在企业微信管理后台完成以下配置。

### 第一步：创建机器人

进入：工作台 → 智能机器人 → 新建机器人

### 第二步：开启 API 模式

进入机器人编辑页，切换为 **API 模式**。企业微信将向开发者推送用户消息和事件。
- ![创建智能机器人 API 模式 — 长连接方式](https://wework.qpic.cn/wwpic3az/807249_W7qYIQzPQbiw7S__1786716563/0)

API 模式支持两种连接方式，选择其一配置：

| 连接方式 | 适用场景 |
|---|---|
| 长连接 | 内网部署、对实时性要求高、需要主动推送消息 |
| URL 回调 | 服务器有公网 IP、对高可用有要求 |

### 第三步：获取凭证

在机器人管理后台进入机器人详情页，可查看并复制对应的凭证：

| 连接方式 | 所需凭证 |
|---|---|
| 长连接 | `BotID`、`Secret` |
| URL 回调 | `Token`、`EncodingAESKey` |
- ![智能机器人详情页 — 获取长连接凭证](https://wework.qpic.cn/wwpic3az/276165_zMmLmaIATGepAaz_1786716806/0)

> 请妥善保管凭证，切勿泄露。

## CLI / MCP 前置配置

使用CLI 或 MCP 能力前，需完成以下配置。

### 安装 CLI

参考 [CLI 概述](#61944) 完成安装与初始化。

### 能力授权

CLI 和 MCP 访问企业数据，需要成员在机器人管理后台完成能力授权：

进入机器人编辑页 → 点击「可使用权限」→ 选择需要的能力授权
- ![创建智能机器人 API 模式 — 可使用权限](https://wework.qpic.cn/wwpic3az/277234_HDRT1ZtmR1OnUbr_1786716650/0)

每个能力独立授权，授权后方可通过 CLI 命令或 MCP 工具调用对应数据。
