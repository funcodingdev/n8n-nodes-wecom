## 概述

当用户与智能机器人进行交互时，企业微信会将相关交互事件回调到开发者设置的回调 URL，开发者可在**响应包**中直接回复消息，实现被动回复。

目前支持被动回复的场景：

1. 用户当天首次进入机器人单聊会话 → 回复欢迎语
2. 用户向机器人发送消息 → 回复消息
3. 用户点击模板卡片相关按钮 → 回复消息更新模板卡片

> 具体流程参考[接收消息回调](#62163)与[接收事件回调](#62164)。

# 回复欢迎语

收到[进入会话事件](#62164/进入会话事件)时，可被动回复文本消息或模板卡片消息。

## 文本消息

```json
{
 "msgtype": "text",
 "text": {
 "content": "hello\nI'm RobotA\n"
 }
}
```

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `text` |
| text.content | String | 是 | 文本内容 |

> 目前仅进入会话回调事件时支持被动回复文本消息。

## 模板卡片消息

```json
{
 "msgtype": "template_card",
 "template_card": {
 "card_type": "multiple_interaction",
 "source": {
 "icon_url": "https://wework.qpic.cn/wwpic/252813_jOfDHtcISzuodLa_1629280209/0",
 "desc": "企业微信"
 },
 "main_title": {
 "title": "欢迎使用企业微信",
 "desc": "您的好友正在邀请您加入企业微信"
 },
 "select_list": [...],
 "submit_button": {
 "text": "提交",
 "key": "submit_key"
 },
 "task_id": "task_id"
 }
}
```

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `template_card` |
| template_card | Object | 是 | 模板卡片结构体，参考[模板卡片类型](#62160) |

> 目前仅进入会话回调事件或接收消息回调时支持被动回复模板卡片消息。

# 回复用户消息

收到[消息回调](#62163)时，可被动回复流式消息或模板卡片消息。

## 流式消息回复

```json
{
 "msgtype": "stream",
 "stream": {
 "id": "STREAMID",
 "finish": false,
 "content": "**广州**今日天气：29度，大部分多云，降雨概率：60%",
 "msg_item": [
 {
 "msgtype": "image",
 "image": {
 "base64": "BASE64",
 "md5": "MD5"
 }
 }
 ],
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `stream` |
| stream.id | String | 首次回复必填 | 自定义的唯一 id，首次回复时设置，后续刷新回调根据此 id 返回最新流式消息 |
| stream.finish | Bool | 否 | 流式消息是否结束 |
| stream.content | String | 否 | 流式消息内容，最长不超过 20480 字节，必须是 UTF-8 编码。特殊的，第一次回复内容为 `"1"`，第二次回复 `"123"`，则消息展示内容为 `"123"` |
| stream.msg_item | Object[] | 否 | 流式消息图文混排消息列表 |
| stream.msg_item.msgtype | String | 否 | 图文混排类型，目前支持 `image`。仅在 `finish=true` 的最后一次回复中设置 |
| stream.msg_item.image | Object | 否 | 图片资源，最多支持 10 个|
| image.base64 | String | 是 | 图片内容的 Base64 编码，图片最大不超过 10M，支持 JPG、PNG 格式 |
| image.md5 | String | 是 | 图片内容（Base64 编码前）的 MD5 值 |
| stream.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62164/用户反馈事件)，有效长度 256 字节以内，UTF-8 编码 |

> 流式消息 `content` 字段支持常见的 [Markdown 格式](#)。
> 若`content` 中包含思考过程`<think></think>` 标签，客户端会展示思考过程。
> 若回复内容包含图片，仅在最后一次回复（`finish=true`）时支持设置 `msgtype` 为 `image` 的`msg_item`。

## 模板卡片消息

```json
{
 "msgtype": "template_card",
 "template_card": {
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `template_card` |
| template_card | Object | 是 | 模板卡片结构体，参考[模板卡片类型](#62160) |
| template_card.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62164/用户反馈事件)，有效长度 256 字节以内，UTF-8 编码 |

## 流式消息 + 模板卡片回复

若需要同时回复流式消息和模板卡片，可使用该消息类型。

> 首次回复时必须返回 stream 的 id。
> template_card 可在首次回复时包含，也可在收到流式消息刷新事件时回复，但同一条消息只能回复一次。

```json
{
 "msgtype": "stream_with_template_card",
 "stream": {
 "id": "STREAMID",
 "finish": false,
 "content": "**广州**今日天气：29度，大部分多云，降雨概率：60%",
 "feedback": {
 "id": "FEEDBACKID"
 }
 },
 "template_card": {
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `stream_with_template_card` |
| stream | Object | 是 | 参考[流式消息回复](#流式消息回复) |
| template_card | Object | 否 | 模板卡片结构体，参考[模板卡片类型](#62160) |

# 回复消息更新模板卡片

收到[模板卡片事件](#62164/模板卡片事件)后，可在响应包中回复此消息类型，即时更新卡片内容。

```json
{
 "response_type": "update_template_card",
 "userids": ["USERID1", "USERID2"],
 "template_card": {
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| response_type | String | 是 | 固定为 `update_template_card` |
| userids | String[] | 否 | 要替换模板卡片的 userid 列表，仅对群聊会话类型有效。不填则替换该消息涉及的所有用户 |
| template_card | Object | 是 | 要替换的模板卡片结构体，参考[模板卡片类型](#62160) |
| template_card.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62164/用户反馈事件)，替换用户模板会覆盖原先消息的反馈信息 |

> 注：模板卡片中的 `task_id` 需与回调收到的 `task_id` 一致。
