## 概述

当用户与智能机器人发生交互并发送消息时，企业微信会将消息加密后回调给机器人配置的接收消息 URL。开发者接收并处理回调消息，即可实现丰富的自定义功能。

目前支持触发消息回调的交互场景：

1. 用户群里@智能机器人 或单聊中向机器人发送**文本消息**
2. 用户群里 @智能机器人 或单聊中向机器人发送**图文混排消息**
3. 用户单聊中向机器人发送**图片消息**
4. 用户单聊中向机器人发送**语音消息**
5. 用户单聊中向机器人发送**本地文件消息**
6. 用户单聊中向机器人发送**视频消息**
7. 用户群里 @智能机器人 或单聊中向机器人发送**引用消息**

**流程说明：**

1. 当用户跟智能机器人交互发送支持的消息类型时，企业微信后台会向开发者后台推送[消息推送](#消息推送)。用户跟同一个智能机器人最多同时有三条消息交互中。
2. 开发者回调 URL 接收到新消息推送后：可选择生成[流式消息回复](#62165/流式消息回复)，并使用用户消息内容调用大模型/AI Agent；也可直接回复[模板卡片消息](#62160)。
3. 若开发者回复消息类型包含流式消息，企业微信在未收到流式消息回复结束前，会不断向开发者回调URL 推送[流式消息刷新](#流式消息刷新)（从用户发消息开始最多等待 10 分钟，超过 10 分钟结束推送）。开发者接收到流式消息刷新后，继续生成[流式消息回复](#62165/流式消息回复)。

> 接收消息与被动回复消息都是加密的，加密方式参考[加解密方案](#62162)。
> 请妥善保管你的 URL、Token、Encoding-AESKey，切勿泄露给他人。

## 消息推送

## 通用字段说明

所有消息类型的回调均包含以下通用字段：

```json
{
 "msgid": "MSGID",
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "response_url": "RESPONSEURL",
 "msgtype": "msgtype_name",
 "msgtype_name": {}
}
```

| 参数 | 说明 |
|---|---|
| msgid | 本次回调的唯一性标志，开发者需据此进行事件排重（可能因网络等原因重复回调）|
| aibotid | 智能机器人 id |
| chatid | 会话 id，仅群聊类型时返回 |
| chattype | 会话类型，`single`\`group`，分别表示：单聊\群聊 |
| from.userid | 操作者的 userid。如果智能机器人创建者为企业超级管理员，则为明文 userid，否则为企业主体下的加密 userid |
| response_url | 支持主动回复消息的临时 [url](#62166) |
| msgtype | 消息类型，同时也是消息内容的字段名。取值范围：[text](#文本消息)、[image](#图片消息)、[mixed](#图文混排消息)、[voice](#语音消息)、[file](#文件消息)、[video](#视频消息) |
| msgtype_name | 消息内容结构体，字段名与 msgtype 的值一致，例如 msgtype 为 `text` 时，消息内容字段名为 `text` |

## 流式消息刷新

当开发者首次回复流式消息后，企业微信会持续向回调 URL 推送流式消息刷新事件，直到开发者回复 `finish=true`。

```json
{
 "msgid": "CAIQz7\/MjQYY\/NGagIOAgAMgl8jK\/gI=",
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "stream",
 "stream": {
 "id": "STREAMID"
 }
}
```

**参数说明：**

| 参数 | 说明 |
|---|---|
| msgid | 本次回调的唯一性标志，开发者需据此进行事件排重（可能因网络等原因重复回调）|
| aibotid | 智能机器人 id |
| chatid | 会话 id，仅群聊类型时返回 |
| chattype | 会话类型，`single`\`group`，分别表示：单聊\群聊 |
| from.userid | 操作者的 userid |
| msgtype | 固定是 `stream`。**该消息事件仅支持[流式消息回复](#62165/流式消息回复)** |
| stream.id | 流式消息的 id，开发者根据该 id 返回对应的流式消息更新内容 |

## 多媒体资源解密

图片、文件、视频回调中的 `url` 下载到的资源均经过加密，不能直接打开，需要先解密后使用。

**加密方式说明：**

-算法：AES-256-CBC
- 密钥（AESKey）：与[回调加解密的 Encoding-AESKey](#62162) 相同，Base64 解码后得到 32 字节 AESKey
- IV：取 AESKey 前 16 字节
- 填充：PKCS#7，填充至 32 字节的倍数

**Python 解密示例：**

```python
import base64
from Crypto.Cipher import AES

def decrypt_media(encoding_aes_key, encrypted_data):
 """
 解密多媒体资源
 :param encoding_aes_key: 管理后台配置的 Encoding-AESKey（字符串）
 :param encrypted_data: 下载到的加密文件内容（bytes）
 :return: 解密后的文件内容（bytes）
 """
 # Base64 解码得到 32 字节 AESKey
 aes_key = base64.b64decode(encoding_aes_key + '=')
 # IV 取 AESKey 前 16 字节
 iv = aes_key[:16]
 # AES-256-CBC 解密
 cipher = AES.new(aes_key, AES.MODE_CBC, iv)
 decrypted = cipher.decrypt(encrypted_data)
 #去除 PKCS#7 填充
 pad_len = decrypted[-1]
 return decrypted[:-pad_len]

## 使用示例
import requests

encoding_aes_key = "YOUR_ENCODING_AES_KEY" # 管理后台配置的 Encoding-AESKey
url = "MEDIA_URL" # 回调中的 url 字段

## 下载加密文件
resp = requests.get(url)
if resp.status_code != 200:
 raise Exception(f"下载失败（status={resp.status_code}），媒体文件链接可能已过期，请重新获取")

## 解密
raw_data = decrypt_media(encoding_aes_key, resp.content)
```
