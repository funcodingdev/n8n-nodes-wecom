## 概述

当用户与智能机器人发生交互时，企业微信会将事件加密后回调给机器人配置的接收消息 URL，开发者可根据事件类型做出相应的响应。

目前支持的事件类型：

- [进入会话事件](#进入会话事件)：用户当天首次进入机器人单聊会话
- [模板卡片事件](#模板卡片事件)：用户点击模板卡片中的交互按钮
- [用户反馈事件](#用户反馈事件)：用户对机器人回复进行点赞/踩等反馈

---

## 事件通用格式

所有事件回调均遵循以下通用协议格式：

```json
{
 "msgid": "CAIQ16HMjQYY\/NGagIOAgAMgq4KM0AI=",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "single",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "eventtype_name",
 "eventtype_name": {}
 }
}
```

**参数说明：**

| 参数 | 是否必填 | 说明 |
|---|---|---|
| msgid | 是 | 本次回调的唯一性标志，开发者需据此进行事件排重 |
| create_time | 是 | 本次回调事件产生的时间 |
| aibotid | 是 | 智能机器人 id |
| chatid | 否 | 会话 id，单聊时为空，群聊时为群聊 id |
| chattype | 是 | 会话类型，`single`\`group`，分别表示：单聊\群聊 |
| from.userid | 是 | 操作者的 userid |
| msgtype | 是 | 消息类型，事件通知固定为 `event` |
| event.eventtype | 是 | 事件类型，例如 `template_card_event` |
| event.eventtype_name | 否 | 具体的事件结构体，字段名与 eventtype 值一致 |

## 事件格式

## 进入会话事件

当用户当天首次进入智能机器人单聊会话时触发。开发者可回复一条文本消息或模板卡片消息。

> 若未回复消息，用户当天再次进入也不再推送进入会话事件。

```json
{
 "msgid": "CAIQ16HMjQYY\/NGagIOAgAMgq4KM0AI=",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "enter_chat"
 }
}
```

| 参数 | 说明 |
|---|---|
| eventtype | 事件类型，此处固定为 `enter_chat` |

## 模板卡片事件

用户点击按钮交互、投票选择和多项选择模板卡片中的按钮后触发。

> 企业微信服务只会发起一次请求，在五秒内收不到响应会断掉连接并丢弃该回调事件。

**模板卡片事件通用格式：**

```json
{
 "msgid": "CAIQ16HMjQYY\/NGagIOAgAMgq4KM0AI=",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "from": {
 "userid": "USERID"
 },
 "chatid": "CHATID",
 "chattype": "group",
 "response_url": "RESPONSEURL",
 "msgtype": "event",
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "vote_interaction",
 "event_key": "button_replace_text",
 "task_id": "fBmjTL7ErRCQSNA6GZKMlcFiWX1shOvg",
 "selected_items": {
 "selected_item": [
 {
 "question_key": "button_selection_key1",
 "option_ids": {
 "option_id": ["button_selection_id1"]
 }
 }
 ]
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| response_url | 支持主动回复消息的 [url](#62166) |
| event.eventtype | 固定为 `template_card_event` |

**TemplateCardEvent 结构说明：**

| 参数 | 是否必填 | 说明 |
|---|---|---|
| card_type | 是 | 模板卡片类型，详见下方各子类型说明 |
| event_key | 是 | 用户点击的按钮 key |
| task_id | 是 | 用户点击的交互模板卡片的 task_id |
| selected_items | 否 | 用户点击提交的选择框数据 |

**SelectedItem 结构说明：**

| 参数 | 说明 |
|---|---|
| question_key | 用户点击提交的选择框的 key值 |
| option_ids.option_id | 用户选择的选项。单选时数组只有一个值，多选时可能有多个值 |

### 按钮交互模板卡片事件

用户点击按钮交互卡片的按钮时触发。

```json
{
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "button_interaction",
 "event_key": "button_replace_text",
 "task_id": "fBmjTL7ErRCQSNA6GZKMlcFiWX1shOvg",
 "selected_items": {
 "selected_item": [
 {
 "question_key": "button_selection_key1",
 "option_ids": {
 "option_id": ["button_selection_id1"]
 }
 }
 ]
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| card_type | 此处固定为 `button_interaction` |
| selected_items | 下拉式选择器选择的数据 |

### 投票选择模板卡片事件

用户选择选项后点击提交按钮时触发。

```json
{
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "vote_interaction",
 "event_key": "button_replace_text",
 "task_id": "fBmjTL7ErRCQSNA6GZKMlcFiWX1shOvg",
 "selected_items": {
 "selected_item": [
 {
 "question_key": "button_selection_key1",
 "option_ids": {
 "option_id": ["one", "two"]
 }
 }
 ]
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| card_type | 此处固定为 `vote_interaction` |
| selected_items | 用户点击提交的投票选择框数据 |

### 多项选择模板卡片事件

用户在下拉框选择选项后点击提交按钮时触发。

```json
{
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "multiple_interaction",
 "event_key": "button_replace_text",
 "task_id": "fBmjTL7ErRCQSNA6GZKMlcFiWX1shOvg",
 "selected_items": {
 "selected_item": [
 {
 "question_key": "button_selection_key1",
 "option_ids": {
 "option_id": ["button_selection_id1"]
 }
 },
 {
 "question_key": "button_selection_key2",
 "option_ids": {
 "option_id": ["button_selection_id2"]
 }
 }
 ]
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| card_type | 此处固定为 `multiple_interaction` |
| selected_items | 用户点击提交的下拉菜单选择框列表数据 |

### 模板卡片右上角菜单事件

用户点击文本通知、图文展示和按钮交互卡片右上角菜单中的选项时触发。

```json
{
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "text_notice",
 "event_key": "button_replace_text",
 "task_id": "fBmjTL7ErRCQSNA6GZKMlcFiWX1shOvg"
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| card_type | 此处可能为 `text_notice`、`news_notice`或 `button_interaction` |

## 用户反馈事件

当开发者在回复消息中设置了反馈信息，用户进行点赞/踩操作时触发。
- ![](https://wework.qpic.cn/wwpic3az/951882_QQWUKEVcS-yEm3B_1764061549/0)

> 若回复消息中未设置反馈信息，用户点击反馈后不会触发该事件。
> 该事件目前**仅支持回复空包**，不支持回复新消息或更新卡片消息。

```json
{
 "msgid": "CAIQ16HMjQYY\/NGagIOAgAMgq4KM0AI=",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "feedback_event",
 "feedback_event": {
 "id": "FEEDBACKID",
 "type": 2,
 "content": "能再详细一些么",
 "inaccurate_reason_list": [2, 4]
 }
 }
}
```

**参数说明：**

| 参数 | 说明 |
|---|---|
| eventtype | 事件类型，此处固定为 `feedback_event` |
| feedback_event.id | [回复消息](#62165/流式消息回复)中设置的反馈 id |
| feedback_event.type | 反馈类型：</br>`1` 准确</br>`2` 不准确</br>`3` 取消准确或不准确 |
| feedback_event.content | 用户输入的反馈内容，仅不准确反馈类型返回 |
| feedback_event.inaccurate_reason_list | 用户选择的负反馈原因列表，仅不准确反馈类型返回：</br>`1` 与问题无关</br>`2` 内容不完整</br>`3` 内容有错误</br>`4` 数据分析错误 |
