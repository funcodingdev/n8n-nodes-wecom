## 概述

本文档说明各类型模板卡片的 **TemplateCard 结构体**，适用于所有需要发送模板卡片消息的场景（被动回复、主动回复、主动推送）。

目前支持以下 5 种卡片类型：

| 卡片类型 | card_type | 说明 |
|---|---|---|
| [文本通知](#文本通知模板卡片) | text_notice | 纯文本内容展示，支持右上角菜单 |
| [图文展示](#图文展示模板卡片) | news_notice | 图文并排展示，支持右上角菜单 |
| [按钮交互](#按钮交互模板卡片) | button_interaction | 带可点击按钮，用户点击触发事件回调 |
| [投票选择](#投票选择模板卡片) | vote_interaction | 单选/多选题，用户提交后触发事件回调 |
| [多项选择](#多项选择模板卡片) | multiple_interaction | 多个下拉选择器，用户提交后触发事件回调 |

> 点击文本通知卡片和图文展示卡片「跳转指引」区域支持消息智能回复。

| action_menu | Object | 否 | 右上角更多操作按钮，参考 [ActionMenu 结构体](#actionmenu-结构体)。有此字段时 `task_id` 必填 |
| main_title | Object | 否 | 主标题，参考 [MainTitle 结构体](#maintitle-结构体)。`main_title.title` 和 `sub_title_text` 必填其一 |
| emphasis_content | Object | 否 | 关键数据样式，建议不与引用样式共用，参考 [EmphasisContent 结构体](#emphasiscontent-结构体) |
| quote_area | Object | 否 | 引用文献样式，建议不与关键数据共用，参考 [QuoteArea 结构体](#quotearea-结构体) |
| sub_title_text | String | 否 | 二级普通文本，建议不超过 112 字。`main_title.title` 和 `sub_title_text` 必填其一 |
| horizontal_content_list | Object[] | 否 | 二级标题+文本列表，最多 6 条，参考 [HorizontalContent 结构体](#horizontalcontent-结构体) |
| jump_list | Object[] | 否 | 跳转指引列表，最多 3 条，参考 [JumpAction 结构体](#jumpaction-结构体) |
| card_action | Object | 是 | 整体卡片点击跳转事件，参考 [CardAction 结构体](#cardaction-结构体) |
| task_id | String | 否 | 任务 id，有`action_menu` 时必填。同一机器人不可重复，由数字、字母和`_-@` 组成，最长 128 字节 |

# 结构体说明

## Source 结构体

卡片来源样式信息

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| icon_url | String | 否 | 来源图标的 url |
| desc | String | 否 | 来源描述，建议不超过 13 字 |
| desc_color | Int | 否 | 来源文字颜色：`0`（默认）灰色 / `1`黑色 / `2` 红色 / `3` 绿色 |

## ActionMenu 结构体

卡片右上角更多操作按钮

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| desc | String | 是 | 更多操作界面的描述 |
| action_list | Object[] | 是 | 操作列表，1～3 条|
| action_list.text | String | 是 | 操作描述文案 |
| action_list.key | String | 是 | 操作 key 值，用户点击后作为 EventKey 回调，最长 1024 字节，不可重复 |

## MainTitle 结构体

模板卡片主标题

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| title | String | 否 | 一级标题，建议不超过 26 字。`title` 和 `sub_title_text` 必填其一 |
| desc | String | 否 | 标题辅助信息，建议不超过 30 字 |

## EmphasisContent 结构体

关键数据样式

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| title | String | 否 | 数据内容，建议不超过 10 字 |
| desc | String | 否 | 数据描述，建议不超过 15 字 |

## QuoteArea 结构体

引用文献样式

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| type | Int | 否 | 点击事件：`0` 或不填无点击 / `1` 跳转 url / `2` 跳转小程序 |
| url | String | 否 | 跳转 url，type=1 时必填 |
| appid | String | 否 | 小程序 appid，type=2 时必填 |
| pagepath | String | 否 | 小程序 pagepath，type=2 时选填 |
| title | String | 否 | 引用标题 |
| quote_text | String | 否 | 引用文案 |

## HorizontalContent 结构体

二级标题+文本列表

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| type | Int | 否 | 链接类型：`0` 或不填普通文本 / `1` 跳转 url / `3` 跳转成员详情 |
| keyname | String | 是 | 二级标题，建议不超过 5 字 |
| value | String | 否 | 二级文本，建议不超过 26 字 |
| url | String | 否 | 跳转 url，type=1 时必填 |
| userid | String | 否 | 成员 userid，type=3 时必填 |

## JumpAction 结构体

跳转指引样式

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| type | Int | 否 | 跳转类型：`0` 或不填无链接 / `1` 跳转 url / `2` 跳转小程序 / `3` 触发消息智能回复 |
| title | String | 是 | 跳转链接文案，建议不超过 13 字 |
| url | String | 否 | 跳转 url，type=1 时必填 |
| appid | String | 否 | 小程序 appid，type=2 时必填 |
| pagepath | String | 否 | 小程序 pagepath，type=2 时选填 |
| question | String | 否 | 智能问答问题，最长 200 字节，type=3 时必填 |

## CardAction 结构体

整体卡片点击跳转事件

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| type | Int | 是 | 跳转类型：`1` 跳转 url / `2` 打开小程序。text_notice 和 news_notice 取值范围为 [1, 2] |
| url | String | 否 | 跳转 url，type=1 时必填 |
| appid | String | 否 | 小程序 appid，type=2 时必填 |
| pagepath | String | 否 | 小程序 pagepath，type=2 时选填 |

## VerticalContent 结构体

卡片二级垂直内容

| 参数 | 类型 | 必须 | 说明 |
|---|---|---|---|
| title | String | 是 | 卡片二级标题，建议不超过 26 字 |
