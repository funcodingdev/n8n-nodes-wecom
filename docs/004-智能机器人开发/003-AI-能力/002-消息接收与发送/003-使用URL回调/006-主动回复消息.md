## 概述

当用户与智能机器人发生交互时，企业微信会将相关事件回调到开发者设置的回调 URL，回调中会返回一个 `response_url`。开发者处理完业务逻辑后，可向此 URL 发起 HTTP POST 请求主动回复消息，适用于需要异步处理后再回复的场景。

目前会返回 `response_url` 的回调场景：

1. 用户向智能机器人发送消息，参考[接收消息回调](#62163)
2. 用户点击模板卡片相关按钮，参考[接收事件回调](#62164/模板卡片事件)

> 每个 `response_url` 只能调用**一次**，有效期为 **1 小时**，超过有效期将无法使用。

## 如何主动回复

获取到 `response_url` 后，向该地址发起 HTTP POST 请求即可回复消息。

**请求示例（以 curl 发送Markdown 消息为例）：**

```bash
curl 'https://qyapi.weixin.qq.com/cgi-bin/aibot/response?response_code=RESPONSE_CODE' \
 -H 'Content-Type: application/json' \
 -d '
{
 "msgtype": "markdown",
 "markdown": {
 "content": "hello world"
 }
}'
```

> `response_url` 已包含鉴权信息，直接 POST 即可，无需额外签名。
> `content` 必须是 UTF-8 编码。

## 消息类型及数据格式

### Markdown 消息

```json
{
 "msgtype": "markdown",
 "markdown": {
 "content": "# 标题\n**加粗**\n- 列表项",
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `markdown` |
| markdown.content | String | 是 | 消息内容，最长不超过 20480 字节，必须是 UTF-8 编码 |
| markdown.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62164/用户反馈事件)，有效长度 256 字节以内，UTF-8 编码 |

> `content` 字段支持常见的 [Markdown 格式](#)。

### 模板卡片消息

```json
{
 "msgtype": "template_card",
 "template_card": {
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `template_card` |
| template_card | Object | 是 | 模板卡片结构体，参考[模板卡片类型](#62160) |
| template_card.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62164/用户反馈事件)，有效长度 256 字节以内，UTF-8 编码 |

> 特殊的，因主动回复可能与用户交互触发的回调间隔较长时间，群聊中机器人主动回复消息时会引用触发回调的用户消息或被点击的模板卡片消息。模板卡片消息不支持引用，会默认生成一条空消息进行引用。
