## 概述

用户与智能机器人发生交互时，企业微信会通过长连接推送事件回调（`aibot_event_callback`）。

支持的事件类型：
- [进入会话事件](#进入会话事件)：用户当天首次进入机器人单聊会话
- [模板卡片事件](#模板卡片事件)：用户点击模板卡片中的交互按钮
- [用户反馈事件](#用户反馈事件)：用户对机器人回复进行点赞/踩等反馈
- [连接断开事件](#连接断开事件)：有新连接建立时，系统通知旧连接即将断开（长连接专有）

---

## 通用字段说明

所有事件回调均包含以下通用字段：

```json
{
 "cmd": "aibot_event_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "single",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "eventtype_name"
 }
 }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| cmd | string | 固定值 `aibot_event_callback` |
| headers.req_id | string | 请求唯一标识，**回复消息时需透传此值** |
| body.msgid | string | 本次回调的唯一性标志，用于事件排重 |
| body.create_time | int | 事件产生的时间戳 |
| body.aibotid | string | 智能机器人 BotID |
| body.chatid | string | 会话 id，仅群聊类型时返回 |
| body.chattype | string | 会话类型，`single` 单聊 / `group` 群聊 |
| body.from.userid | string | 事件触发者的 userid。如果智能机器人创建者为企业超级管理员，则为明文 userid，否则为企业主体下的加密 userid |
| body.msgtype | string | 固定为 `event` |
| body.event.eventtype | string | 事件类型 |

## 事件格式

## 进入会话事件

当用户当天首次进入智能机器人单聊会话时触发。开发者可回复文本消息或模板卡片消息。

> 若未回复消息，用户当天再次进入也不再推送进入会话事件。

```json
{
 "cmd": "aibot_event_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "enter_chat"
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| body.event.eventtype | 固定为 `enter_chat` |

---

## 模板卡片事件

用户点击按钮交互、投票选择和多项选择模板卡片中的按钮后触发。

> 企业微信服务只会发起一次请求，在五秒内收不到响应会断掉连接并丢弃该回调事件。

```json
{
 "cmd": "aibot_event_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "response_url": "RESPONSEURL",
 "msgtype": "event",
 "event": {
 "eventtype": "template_card_event",
 "template_card_event": {
 "card_type": "button_interaction",
 "event_key": "KEY",
 "task_id": "TASK_ID",
 "selected_items": {
 "selected_item": [
 {
 "question_key": "question_key1",
 "option_ids": {
 "option_id": [
 "option_id1"
 ]
 }
 }
 ]
 }
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| body.event.eventtype | 固定为 `template_card_event` |
| body.response_url | 支持主动回复消息的 url，参考[回复消息](#62157/更新模板卡片aibot_respond_update_msg) |
| body.event.template_card_event.card_type | 模板卡片类型，`button_interaction` / `vote_interaction` / `multiple_interaction` / `text_notice` / `news_notice` |
| body.event.template_card_event.event_key | 用户点击的按钮 key |
| body.event.template_card_event.task_id | 被点击的模板卡片的 task_id |
| body.event.template_card_event.selected_items | 用户点击提交的选择框数据，选择类卡片时返回 |

各卡片类型的事件详细说明参考[接收 URL 方式 — 模板卡片事件](#62164/模板卡片事件)。

## 用户反馈事件

当开发者在回复消息中设置了反馈信息，用户进行点赞/踩操作时触发。

> 若回复消息中未设置反馈信息，用户点击反馈后不会触发该事件。
> 该事件目前**仅支持回复空包**，不支持回复新消息或更新卡片消息。

```json
{
 "cmd": "aibot_event_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "event",
 "event": {
 "eventtype": "feedback_event",
 "feedback_event": {
 "id": "FEEDBACKID",
 "type": 2,
 "content": "能再详细一些么",
 "inaccurate_reason_list": [
 2,
 4
 ]
 }
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| body.event.eventtype | 固定为 `feedback_event` |
| body.event.feedback_event.id | 回复消息时设置的反馈 id |
| body.event.feedback_event.type | 反馈类型：</br>`1` 准确</br>`2` 不准确</br>`3` 取消准确或不准确 |
| body.event.feedback_event.content | 用户输入的反馈内容，仅不准确反馈类型返回 |
| body.event.feedback_event.inaccurate_reason_list | 用户选择的负反馈原因列表，仅不准确反馈类型返回：</br>`1` 与问题无关</br>`2` 内容不完整</br>`3` 内容有错误</br>`4` 数据分析错误 |

## 连接断开事件

当同一机器人建立新连接并完成订阅后，企业微信会向旧连接推送此事件，并主动断开旧连接。

```json
{
 "cmd": "aibot_event_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "create_time": 1700000000,
 "aibotid": "AIBOTID",
 "msgtype": "event",
 "event": {
 "eventtype": "disconnected_event"
 }
 }
}
```

| 参数 | 说明 |
|---|---|
| body.event.eventtype | 固定为 `disconnected_event` |

> 收到此事件后，开发者应停止使用当前连接，并根据业务需要决定是否重新建立连接。
