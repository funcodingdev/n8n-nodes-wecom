## 概述

长连接模式支持通过分片方式上传临时素材（文件、图片、语音、视频），上传完成后获取 `media_id`，用于[回复消息](#62157)或[主动推送消息](#62158)时引用。

上传流程分三步：

1. **初始化上传**：获取 `upload_id`
2. **逐片上传**：按分片发送文件数据
3. **完成上传**：服务端合并分片并返回 `media_id`
- ![](https://wework.qpic.cn/wwpic3az/601712_psrLYsqyQMWbgse_1773145737/0)

**注意事项：**

- 上传会话有效期为 **30 分钟**，超时未完成的上传会话将自动清理
- 单个分片不能超过 **512KB**（Base64 编码前），最多支持 **100** 个分片
- 分片可以**乱序上传**，重复上传同一分片会被自动忽略（幂等）
- 服务端按`chunk_index` 顺序合并分片
- 上传的临时素材有效期为 **3 天**
- 频率限制：单个机器人不超过 30 次/分钟，1000 次/小时
- 每个请求都会校验当前连接的机器人身份，不同机器人无法操作同一个上传会话
- 连接断开后重连，只要上传会话未过期，可以继续上传未完成的分片

## 上传初始化（aibot_upload_media_init）

**请求示例：**

```json
{
 "cmd": "aibot_upload_media_init",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "type": "file",
 "filename": "test.pdf",
 "total_size": 2333,
 "total_chunks": 5,
 "md5": "MD5"
 }
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_upload_media_init` |
| headers.req_id | string | 是 | 请求唯一标识，不超过 256 字节 |
| body.type | string | 是 | 文件类型：`file`（普通文件）/ `image`（图片）/ `voice`（语音）/ `video`（视频）|
| body.filename | string | 是 | 文件名，不超过 256 字节 |
| body.total_size | int | 是 | 文件总大小（字节）。图片不超过 10MB，语音不超过 2MB，视频不超过 10MB，普通文件不超过 20MB |
| body.total_chunks | int | 是 | 分片数量，不超过 100 个 |
| body.md5 | string | 否 | 文件 MD5，服务端合并后校验完整性 |

>图片支持 png、jpg/jpeg、gif 格式；语音支持 amr 格式；视频支持 mp4 格式。

**响应示例：**

```json
{
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "upload_id": "UPLOADID"
 },
 "errcode": 0,
 "errmsg": "ok"
}
```

| 字段 | 说明 |
|---|---|
| body.upload_id | 本次上传操作的 id，用于将所有分片关联起来 |

## 上传分片（aibot_upload_media_chunk）

**请求示例：**

```json
{
 "cmd": "aibot_upload_media_chunk",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "upload_id": "UPLOADID",
 "chunk_index": 0,
 "base64_data": "BASE64_ENCODED_DATA"
 }
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_upload_media_chunk` |
| headers.req_id | string | 是 | 请求唯一标识，不超过 256 字节 |
| body.upload_id | string | 是 | 初始化时返回的 upload_id |
| body.chunk_index | int | 是 | 分片序号，从 0 开始 |
| body.base64_data | string | 是 | 分片内容经过 Base64 编码后的数据 |

**响应示例：**

```json
{
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "errcode": 0,
 "errmsg": "ok"
}
```

## 完成上传（aibot_upload_media_finish）

所有分片上传完成后，调用此接口通知服务端合并分片。服务端校验所有分片是否齐全、MD5 是否匹配，然后返回 `media_id`。

**请求示例：**

```json
{
 "cmd": "aibot_upload_media_finish",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "upload_id": "UPLOADID"
 }
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_upload_media_finish` |
| headers.req_id | string | 是 | 请求唯一标识 |
| body.upload_id | string | 是 | 初始化时返回的 upload_id |

**响应示例：**

```json
{
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "type": "file",
 "media_id": "1G6nrLmr5EC3MMb_-zK1dDdzmd0p7cNliYu9V5w7o8K0",
 "created_at": "1380000000"
 },
 "errcode": 0,
 "errmsg": "ok"
}
```

| 字段 | 说明 |
|---|---|
| body.type | 文件类型 |
| body.media_id | 媒体文件唯一标识，**3 天内有效** |
| body.created_at | 媒体文件上传时间戳 |
