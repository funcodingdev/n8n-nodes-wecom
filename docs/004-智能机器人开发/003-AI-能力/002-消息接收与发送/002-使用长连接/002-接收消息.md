## 概述

用户向智能机器人发送消息时，企业微信会通过长连接推送消息回调（`aibot_msg_callback`）。

与接收 URL 方式的主要差异：
- 回调消息为**明文**，无需解密
- 多媒体资源（图片/文件/视频）结构体中额外返回 `aeskey` 字段，每个下载链接对应唯一的 aeskey，不同于接收 URL 方式使用统一的 Encoding-AESKey

---

## 消息推送

## 通用字段说明

所有消息类型的回调均包含以下通用字段：

```json
{
 "cmd": "aibot_msg_callback",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "msgid": "MSGID",
 "aibotid": "AIBOTID",
 "chatid": "CHATID",
 "chattype": "group",
 "from": {
 "userid": "USERID"
 },
 "msgtype": "msgtype_name",
 "msgtype_name": {}
 }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| cmd | string | 固定值 `aibot_msg_callback` |
| headers.req_id | string | 请求唯一标识，**回复消息时需透传此值** |
| body.msgid | string | 本次回调的唯一性标志，用于事件排重（可能因网络等原因重复回调）|
| body.aibotid | string | 智能机器人 BotID |
| body.chatid | string | 会话 id，仅群聊类型时返回 |
| body.chattype | string | 会话类型，`single` 单聊 / `group` 群聊 |
| body.from.userid | string | 消息发送者的userid。如果智能机器人创建者为企业超级管理员，则为明文 userid，否则为企业主体下的加密 userid |
| body.msgtype | string | 消息类型，同时也是消息内容的字段名。取值：[text](#文本消息)、[image](#图片消息)、[mixed](#图文混排消息)、[voice](#语音消息)、[file](#文件消息)、[video](#视频消息) |
| body.msgtype_name | object | 消息内容结构体，字段名与 msgtype 值一致 |

## 多媒体资源解密

图片、文件、视频回调中的`url` 下载到的资源均经过加密，需要使用对应的 `aeskey` 解密后使用。

**与接收 URL 方式的区别**：接收 URL 方式使用统一的 Encoding-AESKey 解密所有多媒体资源；长连接方式每个 url 对应唯一的 `aeskey`，直接从回调中获取，无需配置固定密钥。

**加密方式说明：**

- 算法：AES-256-CBC
- 密钥：回调中的 `aeskey` 字段（32 字节，直接使用，无需 Base64 解码）
- IV：取aeskey 前 16 字节
- 填充：PKCS#7，填充至 32 字节的倍数

**Python 解密示例：**

```python
import requests
from Crypto.Cipher import AES

def decrypt_media(aeskey, encrypted_data):
 """
 解密长连接模式下的多媒体资源
 :param aeskey: 回调中返回的 aeskey 字段（32 字节 UTF-8 字符串，直接用作密钥，无需 base64 解码）
 :param encrypted_data: 下载到的加密文件内容（bytes）
 :return: 解密后的文件内容（bytes）
 """
 # aeskey 直接作为密钥（32 字节），IV 取前 16 字节
 key = aeskey.encode('utf-8')
 iv = key[:16]
 # AES-256-CBC 解密
 cipher = AES.new(key, AES.MODE_CBC, iv)
 decrypted = cipher.decrypt(encrypted_data)
 # 去除 PKCS#7 填充
 pad_len = decrypted[-1]
 return decrypted[:-pad_len]

## 使用示例（以图片为例）
aeskey = "AESKEY" # 回调 body.image.aeskey
url = "IMAGE_URL" # 回调 body.image.url

## 下载加密文件
resp = requests.get(url)
if resp.status_code != 200:
 raise Exception(f"下载失败（status={resp.status_code}），媒体文件链接可能已过期，请重新获取")

## 解密
raw_data = decrypt_media(aeskey, resp.content)
```
