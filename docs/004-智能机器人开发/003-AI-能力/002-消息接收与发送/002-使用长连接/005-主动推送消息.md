## 概述

长连接模式下，开发者可在没有用户消息触发的情况下，主动向用户或群聊推送消息。适用场景包括：

- **定时提醒**：定时推送日报、周报、待办提醒等
- **异步任务通知**：后台任务完成后主动通知用户结果
- **告警推送**：系统监控告警主动推送给相关人员

> **前置条件**：需要用户先在会话中给机器人发送过消息，后续机器人才能主动推送消息给该会话。
>
> **频率限制**：无论[回复](#62157)还是主动推送，给某个会话发消息的限制为 30 条/分钟，1000 条/小时。

## 请求格式

**请求示例（通用格式）：**

```json
{
 "cmd": "aibot_send_msg",
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "body": {
 "chatid": "CHATID",
 "chat_type": 1,
 "msgtype": "msgtype_name",
 "msgtype_name": {}
 }
}
```

**请求字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| cmd | string | 是 | 固定值 `aibot_send_msg` |
| headers.req_id | string | 是 | 请求唯一标识，由开发者自行生成 |
| body.chatid | string | 是 | 会话 id。单聊填用户的 userid，群聊填回调事件中获取的 chatid |
| body.chat_type | uint32 | 否 | 会话类型：`1` 单聊 / `2` 群聊 / `0` 或不填则自动兼容（优先按群聊处理，建议明确指定） |
| body.msgtype | string | 是 | 消息类型，同时也是消息内容的字段名。支持：[markdown](#markdown-消息)、[template_card](#模板卡片消息)、[file](#文件消息)、[image](#图片消息)、[voice](#语音消息)、[video](#视频消息) |
| body.msgtype_name | object | 是 | 消息内容结构体，字段名与 msgtype 值一致 |

**响应示例：**

```json
{
 "headers": {
 "req_id": "REQUEST_ID"
 },
 "errcode": 0,
 "errmsg": "ok"
}
```

## 消息类型格式说明

### Markdown 消息

```json
{
 "msgtype": "markdown",
 "markdown": {
 "content": "# 标题\n**加粗**\n- 列表项",
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `markdown` |
| markdown.content | String | 是 | 消息内容，最长不超过 20480 字节，必须是 UTF-8 编码，支持常见 [Markdown 格式](#) |
| markdown.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62156/支持的事件类型)，有效长度256 字节以内，UTF-8 编码 |

### 模板卡片消息

```json
{
 "msgtype": "template_card",
 "template_card": {
 "feedback": {
 "id": "FEEDBACKID"
 }
 }
}
```

| 参数 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| msgtype | String | 是 | 固定为 `template_card` |
| template_card | Object | 是 | 模板卡片结构体，参考[模板卡片类型](#62160) |
| template_card.feedback.id | String | 否 | 不为空时，用户反馈会触发[反馈事件](#62156/支持的事件类型)，有效长度 256 字节以内，UTF-8 编码 |

### 文件消息

```json
{
 "msgtype": "file",
 "file": {
 "media_id": "MEDIA_ID"
 }
}
```

| 参数 | 是否必填 | 说明 |
|---|---|---|
| msgtype | 是 | 固定为 `file` |
| file.media_id | 是 | 文件 id，通过[上传临时素材](#62159)接口获取 |

### 图片消息

```json
{
 "msgtype": "image",
 "image": {
 "media_id": "MEDIA_ID"
 }
}
```

| 参数 | 是否必填 | 说明 |
|---|---|---|
| msgtype | 是 | 固定为 `image` |
| image.media_id | 是 | 图片媒体文件 id，通过[上传临时素材](#62159)接口获取 |

### 语音消息

```json
{
 "msgtype": "voice",
 "voice": {
 "media_id": "MEDIA_ID"
 }
}
```

| 参数 | 是否必填 | 说明 |
|---|---|---|
| msgtype | 是 | 固定为 `voice` |
| voice.media_id | 是 | 语音文件 id，通过[上传临时素材](#62159)接口获取 |

### 视频消息

```json
{
 "msgtype": "video",
 "video": {
 "media_id": "MEDIA_ID",
 "title": "Title",
 "description": "Description"
 }
}
```

| 参数 | 是否必填 | 说明 |
|---|---|---|
| msgtype | 是 | 固定为 `video` |
| video.media_id | 是 | 视频媒体文件 id，通过[上传临时素材](#62159)接口获取 |
| video.title | 否 | 视频消息标题，不超过 64 字节 |
| video.description | 否 | 视频消息描述，不超过 512 字节 |
