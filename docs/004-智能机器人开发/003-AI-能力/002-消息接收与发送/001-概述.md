## 概述

开启 API 模式后，企业微信会将用户发送的消息和触发的事件，通过回调推送给开发者的服务。开发者处理完业务逻辑后，可以回复消息或主动向用户推送内容。

---

## 连接方式

API 模式支持两种连接方式，两者**互斥**，同一时间只能启用其中一种：

| 连接方式 | 适用场景 | 详细文档 |
|---|---|---|
| 长连接 | 内网部署、对实时性要求高、需要主动推送消息 | [使用长连接](#62154) |
| URL 回调 | 服务器有公网 IP、对高可用有要求（支持多实例负载均衡） | [使用 URL 回调](#62161) |

> 切换连接方式后，原有的回调地址或长连接将立即失效。

### 连接方式对比

| 特性 | 长连接 | URL 回调 |
|---|---|---|
| 服务端要求 | 无需固定公网 IP | 需要公网可访问的回调 URL |
| 消息加解密 | 无需，明文传输 | 需要 |
| 流式消息 | 开发者主动推送，无需等待轮询 | 企业微信轮询回调获取最新内容 |
| 素材上传 | 支持（[上传临时素材](#62159)） | 不支持 |
| 高可用 | 同一时间仅允许一个有效连接 | 支持多实例负载均衡 |
| 开发复杂度 | 低（官方 SDK 内置心跳与断线重连） | 低 |
