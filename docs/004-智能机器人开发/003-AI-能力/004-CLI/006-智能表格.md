智能表格服务，提供信息获取、结构修改、记录增删改查、视图管理及图表管理等能力。

> 使用前需在机器人管理后台授权「**文档**」能力权限，授权方式参考[开发前必读 — 能力授权](#62131/能力授权)。

## 命令说明

| 命令 | 说明 |
|---|---|
| `wecom-cli smartsheet create` | 新建智能表格文档，支持初始表结构与内容 |
| `wecom-cli smartsheet get` | 获取智能表格的基本信息，包含子表列表（子表 ID、名称、类型、行列数、前五列信息等） |
| `wecom-cli smartsheet import` | 导入 xlsx 创建智能表格 |
| `wecom-cli smartsheet charts add` | 修改仪表盘的图表，支持增加图表配置 |
| `wecom-cli smartsheet charts delete` | 修改仪表盘的图表，支持删除图表配置 |
| `wecom-cli smartsheet charts list` | 拉取智能表格的图表列表 |
| `wecom-cli smartsheet charts update` | 修改仪表盘的图表，支持更新图表配置 |
| `wecom-cli smartsheet fields add` | 智能表格新增字段 |
| `wecom-cli smartsheet fields delete` | 智能表格删除字段 |
| `wecom-cli smartsheet fields list` | 拉取智能表格的字段列表 |
| `wecom-cli smartsheet fields update` | 智能表格更新字段 |
| `wecom-cli smartsheet files upload` | 上传文件到文档,得到url |
| `wecom-cli smartsheet images upload` | 上传图片到文档,得到url |
| `wecom-cli smartsheet records add` | 批量新增智能表格行记录 |
| `wecom-cli smartsheet records delete` | 批量删除智能表格行记录 |
| `wecom-cli smartsheet records list` | 读取智能表格数据，支持读取字段定义(fields)、图表(charts)、视图(views)、记录(records)，支持排序、过滤和分页 |
| `wecom-cli smartsheet records query` | 通过 SQL 查询仪表盘数据，支持异步轮询；首次请求 task_id 为空，data_initing=true 时按 task_id 重试 |
| `wecom-cli smartsheet records update` | 批量增加/更新/删除智能表格记录（行数据） |
| `wecom-cli smartsheet sheets add` | 智能表格新增子表 |
| `wecom-cli smartsheet sheets delete` | 智能表格删除子表 |
| `wecom-cli smartsheet sheets list` | 获取智能表格的基本信息，包含子表列表（子表 ID、名称、类型、行列数、前五列信息等） |
| `wecom-cli smartsheet sheets update` | 修改智能表格结构，支持增加/更新/删除子表和列字段 |
| `wecom-cli smartsheet views add` | 修改智能表格视图，增加视图配置 |
| `wecom-cli smartsheet views delete` | 修改智能表格视图，支持删除视图配置 |
| `wecom-cli smartsheet views list` | 拉取智能表格的视图列表 |
| `wecom-cli smartsheet views update` | 修改智能表格视图，支持更新视图配置 |
