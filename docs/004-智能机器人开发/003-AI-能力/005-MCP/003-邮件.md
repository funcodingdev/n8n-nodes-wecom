## 概述

授权邮件权限后，机器人可代替成员读取企业微信邮件，实现邮件的搜索和详情查询。

**支持的能力：**

- 搜索邮件列表（支持关键词、发件人、收件人、时间范围、文件夹、标签等过滤）
- 读取邮件详情

## 授权流程

在机器人管理后台进入机器人编辑页，点击「可使用权限」，选择「邮件」能力授权。

---

## 工具说明

| 工具 | 说明 |
|---|---|
| `mail_get` | 支持通过encode_mail_id获取邮件信息的接口 |
| `mail_search` | 支持搜索邮件和拉取邮件列表 |
| `mail_send` | 支持发送、回复和转发邮件的接口，其中发信还支持日程邮件和会议邮件 |
| `media_download` | 根据 media_id 下载媒体文件。 |
| `media_upload` | 上传媒体文件，返回 media_id |
