## 概述

授权日程权限后，机器人可代替成员访问企业微信日历，实现日程的创建、查询、更新、取消，以及查询成员忙闲状态和推荐共同空闲时段。

**支持的能力：**

- 创建日程
- 查询日程详情
- 查询日程列表（按时间范围）
- 搜索日程
- 更新日程
- 取消日程
- 批量查询成员忙闲状态
- 推荐共同空闲时段

## 授权流程

在机器人管理后台进入机器人编辑页，点击「可使用权限」，选择「日程」能力授权。

## 工具说明

| 工具 | 说明 |
|---|---|
| `calendar_schedules_cancel` | 取消（删除）日程，周期日程需指定编辑规则（仅本次、本次及以后、全部） |
| `calendar_schedules_create` | 创建日程，支持设置标题、时间、地点、备注、参与人、提醒时间、时区、是否全天等信息 |
| `calendar_schedules_get` | 根据日程 ID 获取日程详情，返回日程的完整信息：标题、时间、地点、备注、参与人、提醒、时区、周期规则等 |
| `calendar_schedules_list` | 查询指定时间范围内的日程列表，返回日程的基本信息：标题、开始时间、结束时间、参与人、会议室、地点、备注 |
| `calendar_schedules_search` | 按关键词搜索指定时间范围内的日程，返回匹配的日程列表（标题、时间、参与人、会议室、地点、备注） |
| `calendar_schedules_update` | 更新日程信息（Patch 语义），支持修改标题、时间、地点、备注、新增/移除参与人，周期日程需指定编辑规则 |
| `calendar_schedules_free_list` | 查询指定成员在指定时间范围内的共同空闲时段，返回推荐的空闲时间段列表 |
| `meeting_rooms_search` | 查询会议室。 |
| `meeting_rooms_buildings_list` | 查询企业会议室楼栋信息。 |
