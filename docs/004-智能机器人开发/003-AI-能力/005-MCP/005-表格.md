> 使用前需在机器人管理后台授权「**文档**」能力权限，授权方式参考[开发前必读 — 能力授权](#62131/能力授权)。

## 工具说明

| 工具 | 说明 |
|---|---|
| `sheet_create` | 新建在线表格 |
| `sheet_get` | 获取表格文档基本信息，包含工作表列表（sheet_id、标题、行列数等） |
| `sheet_import_submit` | 提交将外部文件导入为在线表格的任务（异步任务） |
| `sheet_import_query` | 查询 `sheet_import_submit` 提交的异步导入任务状态和结果 |
| `sheet_contents_update` | 更新表格指定范围的单元格数据 |
| `sheet_ranges_get_submit` | 提交读取表格指定范围单元格数据的任务，范围格式遵循 A1 表示法（异步任务） |
| `sheet_ranges_get_query` | 查询 `sheet_ranges_get_submit` 提交的异步读取任务状态和结果 |
| `sheet_rows_append` | 在表格工作表末尾追加一行数据 |
| `sheet_subsheets_add` | 在表格文档中添加新的工作表，可指定标题和插入位置 |
| `sheet_subsheets_delete` | 删除表格文档中指定工作表，删除后不可恢复 |
