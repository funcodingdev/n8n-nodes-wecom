## 概述

授权微盘权限后，机器人可代替成员访问企业微信微盘，实现文件的查询、上传、下载、搜索等操作。

**支持的能力：**

- 下载微盘文件
- 读取文件基础信息（名称、大小、类型、路径等）
- 列出最近浏览的文件
- 搜索微盘文件或文件夹
- 上传文件到微盘
- 重命名文件
- 新建文件夹

## 授权流程

在机器人管理后台进入机器人编辑页，点击「可使用权限」，选择「微盘」能力授权。

## 工具说明

| 工具 | 说明 |
|---|---|
| `disk_files_download_submit` | 异步提交微盘文件下载任务，提交后需使用 `disk_files_download_query` 轮询查询结果 |
| `disk_files_download_query` | 查询异步下载任务的结果，返回文件内容或下载链接 |
| `disk_files_get` | 读取微盘文件的基础信息，包括文件名、大小、类型、路径等元信息 |
| `disk_files_list` | 列出当前用户最近浏览的微盘文件列表 |
| `disk_files_search` | 按关键词搜索微盘文件或文件夹 |
| `disk_files_upload` | 上传本地文件到微盘指定目录 |
| `disk_files_rename` | 重命名微盘中的文件或文件夹 |
| `disk_folders_create` | 在微盘中新建文件夹 |
| `media_download` | 根据 media_id 下载媒体文件 |
| `media_upload` | 上传媒体文件，返回 media_id |
