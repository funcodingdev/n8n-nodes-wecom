请开发者注意，该回调**不是实时回调**，而是每天定时检测触发回调，且单个授权企业每天最多回调一次。

**示例**
```
<xml>
 <ToUserName><
- ![CDATA[toUser]]></ToUserName>
 <FromUserName><
- ![CDATA[sys]]></FromUserName> 
 <CreateTime>1348831860</CreateTime>
 <MsgType><
- ![CDATA[event]]></MsgType>
 <Event><
- ![CDATA[wedrive_insufficient_capacity]]></Event>
</xml>
```

**说明**

 | 参数 | 说明 |
 |---- | ----- |
 | ToUserName | 企业微信CorpID |
 | FromUserName | 此事件该值固定为```sys```，表示该消息由系统生成 |
 | CreateTime | 消息创建时间，unix时间戳|
 | MsgType | 消息类型，此时固定为：```event``` |
 | Event | 事件类型，此时固定为：```wedrive_insufficient_capacity``` |
