### 使用二次验证

管理员需要先在管理端配置使用二次验证的验证页面、验证时机。
- ![MTY4ODg1MDg5MTkxNTc2OA_109750_f19LJnopu1NqjjOu_1699963068.png](https://wework.qpic.cn/wwpic3az/322950_5caaAhyHSNaz_3u_1723444486/0)
- ![MTY4ODg1MDg5MTkxNTc2OA_439036_nM3jGGx_A1E1TmkI_1699963040.png](https://wework.qpic.cn/wwpic3az/424290_yWCZ4hQESX6G4bW_1723444525/0)

当成员触发了二次验证时，会自动跳转到企业配置的验证页面，并且会带上如下参数：code=CODE。拿到code之后企业可以通过[获取用户二次验证信息](#50693)接口获取到需要验证成员的userid和tfa_code，待验证用户身份信息无误后，再调用[通过二次验证](#50695)让成员进入企业或者正常使用。
