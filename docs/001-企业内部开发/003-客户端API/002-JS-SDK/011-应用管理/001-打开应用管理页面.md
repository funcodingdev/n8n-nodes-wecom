## ww.openAppManage([params])

### 功能描述

打开应用管理页面。应用可以使用该接口提供按钮，让企业管理员快速打开应用的管理页面。

通过指定 `page` 参数，可跳转到不同的二级页面，包括应用权限详情页、数据与智能专区相关的权限授权页，以及获客助手权限授权页。

### 平台版本说明

| 平台 | 企业微信版本要求 |
| :- | :- |
| 全平台 | ≥ 4.0.2 |

### 使用限制

- 必须先使用 `ww.register` 进行应用身份注册
- 当前用户需要是企业超级管理员，或具有应用管理权限

### 示例代码

```javascript
// 跳转到应用权限详情页
ww.openAppManage({
 page: "permission",
 suiteId: "wwabcdefghijk",
});

// 跳转到「数据与智能专区」会话数据权限授权页
ww.openAppManage({
 page: "datazone_chat_permission",
});

// 跳转到「数据与智能专区」文档数据权限授权页
ww.openAppManage({
 page: "datazone_doc_permission",
});

// 跳转到「数据与智能专区」知识集数据权限授权页
ww.openAppManage({
 page: "datazone_knowledge_permission",
});

// 跳转到「获客助手」权限授权页
ww.openAppManage({
 page: "customer_acquisition_permission",
});

// 不指定 page，跳转到应用管理首页
ww.openAppManage();
```

### 参数说明

| 参数名 | 类型 | 必填 | 说明 |
| :- | :- | :- | :- |
| page | string | 否 | 指定跳转的二级页面地址，不指定时跳转至应用管理首页。可选值见下方 [page 参数说明](#page-参数说明) |
| suiteId | string | 否 | 指定跳转的关联应用。不指定时，跳转到 agentConfig 注册应用的管理页；指定时，跳转到其他应用管理页，目前仅支持会话内容存档应用。服务商应用调用时，指定的 suiteId 必须为同服务商的应用，应用与当前企业需要有授权关系，且当前用户必须是企业超级管理员 |

#### page 参数说明

| page 参数值 | 权限名称 | 权限要求 |
| :- | :- | :- |
| permission | 应用权限详情页 | 无额外要求 |
| datazone_chat_permission | 「数据与智能专区」会话数据权限 | 1. 调用身份为超级管理员<br>2. 应用需要满足勾选了"数据与智能专区权限"（灰度服务商，则为"数据与智能专区权限-分析企业会话内容数据"）<br>3. 应用类型为第三方应用/代开发应用（注：不支持上下游共享应用） |
| datazone_doc_permission | 「数据与智能专区」文档数据权限 | 1. 调用身份为超级管理员<br>2. 应用需要满足勾选了"数据与智能专区权限-分析企业文档数据"<br>3. 应用类型为第三方应用（注：不支持上下游共享应用） |
| datazone_knowledge_permission | 「数据与智能专区」知识集数据权限 | 1. 调用身份为超级管理员<br>2. 应用需要满足勾选了"数据与智能专区权限-分析企业知识集数据"<br>3. 应用类型为第三方应用（注：不支持上下游共享应用） |
| customer_acquisition_permission | 「获客助手」权限 | 1. 调用身份为超级管理员或应用分级管理员<br>2. 应用需要满足勾选了"获客助手权限"<br>3. 应用类型为第三方应用/代开发应用（注：不支持上下游共享应用） |

### 返回结果说明

| 参数名 | 类型 | 说明 |
| :- | :- | :- |
| res | Object | 返回信息 |
| res.err_msg | string | 执行结果。`"openAppManage:ok"` 表示执行成功，否则为报错信息 |

## 旧版jweixin调用
### 示例代码
```js
wx.invoke('openAppManage', 
 {
 "page": "permission", // 非必填，指定跳转的页面地址
 "suiteId": "wwabcdefghijk", // 非必填，指定跳转的关联应用
 }, 
 function(res){
 if(res.err_msg == "openAppManage:ok") {
 // 调用成功 
 }
 if(res.err_msg == "openAppManage:fail:no permission") {
 // 调用人身份不符合 
 }
 if(res.err_msg == "openAppManage:fail:unknown app") {
 // 应用信息获取失败
 }
 if(res.err_msg == "openAppManage:fail:unsupported app type") {
 // 应用类型不符合要求
 }
 if(res.err_msg == "openAppManage:fail") {
 // 其它错误 
 } 
})
```
