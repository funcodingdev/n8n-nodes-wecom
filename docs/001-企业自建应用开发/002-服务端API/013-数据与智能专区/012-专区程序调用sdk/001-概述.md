企业微信在数据与智能专区中提供一套SDK接口，应用可通过SDK接口获取会话记录与知识集。
专区程序需要通过SDK接口来向企业微信后台发起请求，具体用法参考[专区请求企微后台](#54006/专区请求企微后台)
