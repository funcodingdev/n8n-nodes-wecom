通过微盘[选择文件](#48964)或者文档[选择文档](#48966)返回的文件/文档url信息，可通过此展示组件，将对应的标题展示出来，以便用户快速识别所选择的文件/文档。

组件用法参考[会话展示组件](#50920)。**仅支持企业微信内置浏览器和外部浏览器，不支持小程序。**

###权限说明
组件支持企业自建应用、代开发自建应用和第三方应用调用。

### 支持的元素属性

页面通过 ww-open-data 元素上的属性控制需要渲染的内容：

属性 | 类型 | 必填 | 说明
--- | --- | --- | ---
type | string | 是 | 开放数据类型，此时固定为：fileName，标识为：展示文件/文档标题名
openid | string | 是 | type=fileName，此时 openid 对应 文件/文档url

> 异常情况说明：
> - url错误，展示「链接错误」
> - 非本企业的文件/文档，且用户无浏览权限，展示「暂无权限查看该文档/文件」
> - 文件url，且应用无“微盘”权限，展示「暂无微盘应用权限」
> - 文档url，且应用无“文档”权限，展示「暂无文档应用权限」
